## 三步使用

1. 在已安装 Surge 的 iPhone 上打开 **[surge.loder.my](https://surge.loder.my/)**。
2. 按用途选择模块，点击「导入 Surge」，在 Surge 中检查并确认。
3. 启用模块；脚本改写功能需要按 Surge 提示配置 MITM。

如果按钮没有唤起 Surge，可在网站复制模块地址，到 Surge 的模块页面手动添加。导入链接使用 [Surge 官方 URL Scheme](https://manual.nssurge.com/tools/url-scheme.html)。
